# Architecture

See [system-architecture.md](system-architecture.md) for the repository-derived architecture map. The system uses Next.js App Router server components, client interaction islands, Supabase Auth/SSR, Supabase PostgreSQL with RLS, and a private course-media bucket. The current UI is the Synthetix V2 dark technical SaaS system implemented by the dashboard shell and shared UI primitives; no legacy horizontal dashboard header is present.
